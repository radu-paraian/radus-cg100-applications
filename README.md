# radus-cg100-applications

Simple games for the CASIO fx-CG100 graphing calculator, written in its Python app (MicroPython 1.9.4).

## Running a game

1. Connect the calculator to your computer over USB.
2. Copy the `.py` file to the calculator's storage memory.
3. On the calculator, open the Python app, choose File > Open, pick the file, then run it.

The calculator-specific coding rules are in [AGENTS.md](AGENTS.md).
